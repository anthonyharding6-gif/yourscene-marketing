# YourScene — Landing/Waitlist CRO + Copy

> Applies `cro` + `copywriting` + `signup`. Target: https://yourscene.netlify.app/
> Goal of the page (pre-launch): maximize **waitlist signups** + set up the share/referral loop.

## CRO principles for a waitlist page
1. One job: capture the email/signup. Remove competing CTAs.
2. Above the fold must answer: what is it, who's it for, why care, what do I do. In <5 seconds.
3. Reduce friction: email-only field (or Apple/Google one-tap). Don't ask for more pre-launch.
4. Show, don't tell: the energy-map visual is the hero asset — animate it.
5. Add momentum proof: "Join 1,200+ fans" / "20+ NYC venues already on the map."
6. Make sharing the post-signup action (referral loop — see `outputs/05`).

## Recommended page structure
1. **Hero:** headline + subhead + email capture + animated energy-map.
2. **3 value props** (the messaging pillars, as icons + one line each).
3. **"Where to watch" teaser** — show a few real NYC venues already on the map (social proof + SEO).
4. **How it works** (3 steps: pick your tribes → see the live map → find your people).
5. **Built for the World Cup** band — countdown to Jun 11, match-day hook.
6. **Final CTA** + footer.
