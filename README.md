# YourScene — Marketing

Marketing workspace for **YourScene** (https://yourscene.netlify.app/) — a real-time crowd-energy app for live events, nightlife & watch parties, launching first for **World Cup 2026** (June 11, 2026).

This repo combines a complete launch kit, 43 installed marketing skills, and skill-generated strategy outputs. It is **separate from the app codebase** — marketing only.

## Structure
```
.claude/
  product-marketing.md     ← FOUNDATION (every skill reads this first)
  skills/                  ← 43 marketing skills (live in any Claude Code session here)
marketing-kit/             ← the 13-doc launch kit (gameplan, outreach, social, targets, tracker…)
outputs/                   ← strategy docs generated by applying the skills
  01-marketing-plan.md     (marketing-plan skill — AARRR)
  02-launch-plan.md        (launch skill — ORB framework)
  03-landing-cro-and-copy.md (cro + copywriting + signup)
  04-aso-app-store-listing.md (aso)
  05-referrals-and-community.md (referrals + community-marketing)
```

## How to use the skills
Open this repo in Claude Code. The 43 skills in `.claude/skills/` activate automatically when you work on a matching task — or invoke directly, e.g. `/cold-email`, `/aso`, `/ab-testing`. Every skill reads `.claude/product-marketing.md` for context first, so keep that doc current.

## Highest-value skills to run next (priority for a pre-launch, part-time, $0-budget app)
1. **`ai-seo` / `programmatic-seo`** — build "Where to watch the World Cup in NYC" pages (massive live search demand).
2. **`cold-email`** — upgrade the venue/influencer outreach into tracked sequences.
3. **`social` / `video` / `ad-creative`** — sharpen the Reels + post engine.
4. **`onboarding`** — design the no-empty-map first session.
5. **`analytics`** — instrument waitlist + referral sources before launch.
6. **`co-marketing`** — formalize venue/creator joint pushes.
7. **`competitor-profiling` / `competitors`** — map alternatives (FANZO, Meridian, etc.).
8. **`pricing` / `paywalls` / `revops`** — venue monetization, *after* the network exists.
