# YourScene — Marketing

Marketing workspace for **YourScene** (https://yourscene.netlify.app/) — a real-time crowd-energy app for live events, nightlife & watch parties, launching first for **World Cup 2026** (June 11, 2026).

This repo combines a complete launch kit, 43 installed marketing skills, and skill-generated strategy outputs. It is **separate from the app codebase** — marketing only.

## Structure
```
.claude/
  product-marketing.md     ← FOUNDATION (every skill reads this first)
  skills/                  ← 43 marketing skills (live in any Claude Code session here)
marketing-kit/             ← the 13-doc launch kit (gameplan, outreach, social, targets, tracker…)
outputs/                   ← strategy docs generated by applying the skills
  01-marketing-plan.md     (marketing-plan skill — AARRR)
  02-launch-plan.md        (launch skill — ORB framework)
  03-landing-cro-and-copy.md (cro + copywriting + signup)
  04-aso-app-store-listing.md (aso)
  05-referrals-and-community.md (referrals + community-marketing)
```

## How to use the skills
Open this repo in Claude Code. The 43 skills in `.claude/skills/` activate automatically when you work on a matching task — or invoke directly, e.g. `/cold-email`, `/aso`, `/ab-testing`. Every skill reads `.claude/product-marketing.md` for context first, so keep that doc current.

## Skills applied so far
✅ `product-marketing` · `marketing-plan` · `launch` · `cro` · `copywriting` · `signup` · `aso` · `referrals` · `community-marketing` · `ai-seo` · `programmatic-seo` · `cold-email` · `onboarding` · `analytics` · `emails` · `social` · `co-marketing`

**`co-marketing` outputs (`outputs/13-co-marketing.md`):** partner types + scored shortlist (Harbor #1), 5 launch-ready joint campaigns (Harbor "official launch partner," creator collab, community home-base, joint giveaway, media segment), approach + simple terms + prioritized next actions.

**`social` outputs (`outputs/12-social-strategy.md`):** content pillars, platform priority (IG/TikTok #1), hook formulas, the repurposing engine (1 piece → 15+ posts), weekly calendar, short-form video upgrades (3-second rule), daily engagement routine, metrics.

**`emails` outputs (`outputs/11-email-sequences.md`):** 4 lifecycle sequences — Waitlist Nurture (pre-launch), New-User Onboarding (wired to activation triggers), Stalled Re-Engagement (match-anchored), Venue Onboarding — full subjects/preview/body/CTA + metrics + tooling.

**`analytics` outputs (`outputs/10-analytics-tracking-plan.md` + `outputs/data/utm-builder.csv`):** full tracking plan — waitlist + app event schema (object_action), onboarding funnel instrumentation, per-channel UTM strategy (ready CSV), recommended stack (GA4 + PostHog), north-star metric, privacy/ATT, pre-launch validation checklist.

**`cold-email` outputs (`outputs/08-cold-email-sequences.md`):** 5-touch sequences (day 0/3/7/14/21) for Venues, Influencers, and Communities — lowercase internal subjects, peer voice, new angle per touch, 1-2-3 breakup. Includes 3 personalized venue examples.

**`onboarding` outputs (`outputs/09-onboarding.md`):** first-session activation design that solves the empty-map problem — aha moment in <60s, primed location/push permissions, seeded map, empty-state copy, push/email triggers, activation funnel + targets, 5 A/B experiments.

**`programmatic-seo` outputs (`outputs/07-programmatic-seo.md`):**
- `outputs/data/venues.csv` — single source of truth (20 venues) powering all page types
- `outputs/templates/` — neighborhood / team / venue page templates
- `outputs/content/examples/` — rendered Astoria + Argentina pages
- Plan: ~52-64 pages (neighborhoods × teams × venues × match-days), hub-and-spoke, anti-thin-content rules

**`ai-seo` outputs (`outputs/06-ai-seo.md` + ready-to-deploy files):**
- `outputs/content/where-to-watch-world-cup-nyc.md` — flagship extractable article (20-venue table, FAQ)
- `outputs/site-assets/llms.txt` · `robots.txt` (AI bots + fixed sitemap) · `schema.jsonld` (FAQ/Org/ItemList)
